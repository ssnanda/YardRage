# Yard Rage for iPhone

Yard Rage is a satirical HOA game from ITSpector LLC: patrol the neighborhood, investigate complaints, photograph evidence, manage residents, survive board politics, and try to keep your seat.

This public repository contains installation files and release notes only. The source code is maintained privately.

Official website: [yardrage.com](https://yardrage.com)

## Install with AltStore

Yard Rage requires iOS 13 or later.

### Option 1: Add the Yard Rage source

1. Install [AltStore Classic](https://altstore.io/) on your iPhone using AltServer for macOS or Windows.
2. On iOS 16 or later, enable **Settings → Privacy & Security → Developer Mode**.
3. Open AltStore and add this source URL:

   ```text
   https://raw.githubusercontent.com/ssnanda/YardRage/main/altstore.json
   ```

4. Open the Yard Rage listing and tap **Install**.

### Option 2: Install the IPA manually

1. Download `yardrage.ipa` from the [latest release](https://github.com/ssnanda/YardRage/releases/latest).
2. Open AltStore on your iPhone.
3. Open **My Apps**, tap **+**, and select the downloaded IPA.
4. Keep AltServer available when AltStore needs to install or refresh the app.

For AltStore setup help, use the official [macOS guide](https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos) or [Windows guide](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows).

## Releases

Each GitHub release contains an immutable, versioned Yard Rage IPA. Release downloads and the AltStore source are public; the game source code is not included.
